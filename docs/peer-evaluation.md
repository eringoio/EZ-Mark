# Peer Evaluation

Peer Evaluation is the second product mode in EZ Mark (`peer_review`). Participants rate one another anonymously on a **1–5 rating scale** per **competency** (a rated skill such as teamwork, communication, or clarity — the examples are plain user-entered labels).

## Template vs session

A **template** defines the reusable structure (no actual people or scores):

- competencies (name, description, furigana/ruby printing, optional short printed label);
- rating scale (min/max, default 1–5 with 5-point scale);
- rater groups (used to split scan uploads and compare results by group);
- optional weighting of competencies;
- layout settings: students per page, page orientation (auto/portrait/landscape), density (standard/compact/relaxed).

A **session** (test run) created from the template gets its own roster, rating form PDF, sheets, scans, review queue, and results. The workflow mirrors Standard Tests:

1. Create the session from a template and add/import its roster.
2. Open the peer evaluation builder: arrange target rows per rater, set page breaks/auto-pagination, preview the printed layout, and **generate the PDF** (rating form pages; each rater marks targets 1–5 per competency). QR codes map pages to raters.
3. Print; participants fill in the forms. Anything identifying a rater is not required on the sheet — the form must not carry reviewer names/numbers (printed instruction on the sheet).
4. **Upload scans** (PDF/JPG/JPEG/PNG) per batch, assigning each batch to a rater group.
5. **Review** the unclear/blank/multiple/invalid ratings only.
6. **Results** and **export**.

## Anonymous ratings

- Designs do not print reviewer identity; QR tokens (opaque, no PII) carry page-to-rater mapping.
- Each target row receives a score per competency from every rater; analysis sums averages per competency and rater group.

## Results

After review completes, recalculate to see:

- overall ranking with final scores per target;
- group comparison and group averages (rater groups);
- competency averages;
- per-target detail tables (raw rating counts and values).

## Layout helpers

The builder checks fit before generation: if the columns don't fit the page it suggests reducing competencies/rating scale, hiding furigana, using compact density, adding short printed labels for long titles, or lowering students-per-page — and refuses to generate a printable PDF that wouldn't work, rather than producing an unreadable form.

## Limitations

- Ratings are integer-valued on the configured scale; there are no per-competency weights in scoring except the template's weighting option.
- Scans must be generated by EZ Mark sheets (QR-matched); see [scanning-and-review.md](scanning-and-review.md).
